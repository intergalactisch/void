# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct, in full and without modification.

In short: everyone who contributes — through code, issues, pull requests, discussions, or any other channel — is expected to make this a welcoming environment for people of every background and experience level. Harassment, abuse, and exclusionary behaviour are not tolerated.

## Reporting

If you witness or experience behaviour that violates the Covenant, file a [private report](https://github.com/intergalactisch/void/security/advisories/new) — the maintainer receives it directly without exposing the report publicly. Reports are handled confidentially.

The full text of the Contributor Covenant 2.1 is the authoritative version of this code of conduct and is available at:

- HTML: <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>
- Plain text: <https://www.contributor-covenant.org/version/2/1/code_of_conduct/code_of_conduct.txt>
- Translations (50+ languages): <https://www.contributor-covenant.org/translations>

By participating in this project you agree to abide by its terms.
